# Roadmap

What's planned for halt.ae Workspace. The app shows this list on its **Updates** screen.

- Write items as `- [ ] **Title** - short description`.
- Change `[ ]` to `[x]` when an item ships, and add it to CHANGELOG.md.
- Move items between sections as plans change.

## Now - in progress

- [ ] **macOS app** - The same desktop app for Mac
- [ ] **Markdown import and export** - Bring in an Obsidian vault or a folder of .md files, and export your whole workspace the same way
- [ ] **Find and replace** - Search inside the current note and replace one match or all of them
- [ ] **Sync folder** - Keep your workspace in a folder you choose (OneDrive, Dropbox, iCloud) so it follows you between computers

## Next - coming soon

- [ ] **Databases** - Turn a folder into a table with properties like status, date and owner, plus filters and sorting
- [ ] **Smarter connectors** - Arrows that route around shapes, alignment guides and snapping on the canvas
- [ ] **Comments** - Leave comments on any paragraph or canvas item
- [ ] **Table of contents and footnotes** - For long documents
- [ ] **Tablets and phones** - A layout for small screens and pen drawing with pressure
- [ ] **Offline fonts** - Download your favorite fonts so they work without internet

## Later - ideas we're exploring

- [ ] **Live collaboration** - Shared workspaces where several people can edit at once
- [ ] **Encrypted sync** - Sync between devices with end-to-end encryption
- [ ] **Plugins and themes** - Add new blocks, tools and color themes
- [ ] **Publish to the web** - Share any page as a read-only website
- [ ] **AI assistant** - Summarize notes and turn notes into mind maps, using your own API key
- [ ] **Web clipper** - Save articles and images from your browser into a note

## Done

- [x] **Windows app with one-click updates** - Shipped in 1.0.0
- [x] **Updates screen and auto-update** - Shipped in 1.0.0
- [x] **Workspace layout** - Shipped in 0.9.0
- [x] **Folders, global search and backups** - Shipped in 0.7.0
