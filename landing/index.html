Get started

Up and running in a minute

  1. 1
    DownloadGet the Windows installer. It's about 2 MB and doesn't need admin rights.
  2. 2
    InstallRun it and open Haltspace from the Start menu. If Windows says "Windows protected your PC", click More info → Run anyway.
  3. 3
    Stay updatedHaltspace checks for new versions when it opens. When one is ready, click Restart to update.
